# Healing Garden — Plant Benefit Catalogue

An interactive catalogue for a therapeutic walking garden in Pietermaritzburg,
KwaZulu-Natal. 32 plants grouped by healing benefit (scent, calming colour,
birds, pollinators, shade), each with a photograph, a recognition cue, care
notes and safety guidance — plus name search, benefit filters, a build-your-own
nursery shopping list, a watering & care guide, planting combinations and full
photo credits.

## Viewing it

Open `index.html` in any modern browser, or view the hosted version at:
https://mpumelelodlams.github.io/Healing-garden/

- `index.html` — the interactive catalogue
- `healing_garden_images/` — plant photographs
- `garden_combination_images/` — planting-combination boards
- `Healing_Garden_Plant_Catalogue.pdf` — printable / navigable PDF version

Plant photographs are from Wikimedia Commons under their respective licences;
see the "Photo credits" section in the catalogue for attribution.
